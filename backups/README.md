# Sauvegardes — Darija Academy

Chaque fois qu'une nouvelle version est publiée, la version précédente est copiée ici.
Rien n'est jamais perdu : tu peux revenir à n'importe quelle version en quelques clics.

Chaque dossier existe aussi en `.zip`, pratique à télécharger d'un coup.

## Revenir à une ancienne version (méthode simple)

1. Ouvre le dossier de la version voulue (ex. `backups/v1-avant-darija-academy/`).
2. Télécharge le fichier `.zip` et décompresse-le sur ton ordinateur.
3. Sur la page principale du dépôt GitHub → **Add file → Upload files**.
4. Glisse-dépose **tous** les fichiers décompressés → **Commit changes**.
5. Après 1-2 minutes, l'app en ligne est revenue à cette version.

## Méthode encore plus rapide : l'historique GitHub

GitHub garde automatiquement toutes les versions de chaque fichier. Pour annuler la dernière mise à jour :
1. Page du dépôt → onglet **Commits** (ou clique sur « X commits » en haut de la liste des fichiers).
2. Clique sur le commit que tu veux annuler → bouton **« … » → « Revert »**.
3. Confirme : GitHub crée automatiquement une nouvelle version identique à l'ancienne.
